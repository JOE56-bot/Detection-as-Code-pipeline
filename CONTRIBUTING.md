Contributing

Detection Development

All detection content should follow the project's detection development standards.

Before submitting a detection:

Document the detection purpose.

Include appropriate metadata.

Map the detection to MITRE ATT&CK where applicable.

Consider false positives.

Include testing information.

Validate the detection before submission.

Pull Requests

Pull requests should clearly describe:

What detection was added or modified.

The threat behavior being detected.

Relevant MITRE ATT&CK techniques.

Testing performed.

Any known limitations or false positives.

Security

Do not commit:

Passwords

API keys

Access tokens

Credentials

Private keys

Sensitive environment information

Production security data
